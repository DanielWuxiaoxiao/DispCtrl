Add external radar link pass-through and Qt project integration

Summary:
- Add pass-through support for external radar (system control 512B, control ACK 64B, servo control 32B, servo ACK 32B) without parsing payloads.
- Introduce `ExternalCtrlManager` to send system/servo frames and receive ACKs; expose send helpers and signals via `Controller`.
- Add constants and placeholder structs in `Basic/Protocol.h` (RADAR_CTRL_ID, External* structs).
- Add default network configuration values in `config.toml` for external link (IP/ports/ID).
- Update `DispCtrl.pro` to include new sources/headers/UI (ExternalCtrlManager and `paramWidget/*`) so Qt Creator/qmake builds.
- Address MSVC C4819 warnings by adding `/utf-8` compiler flag in `.pro` and saved sources as UTF-8 where needed.
- Update documentation: `docs/internal_protocol.md` (v5.1 entry + external link sections) and add `docs/changes_2025-12-25.md` summarizing changes and usage.

Files added/updated (high level):
- Added: `Controller/ExternalCtrlManager.h/.cpp`
- Modified: `config.toml`, `Basic/Protocol.h`, `Controller/controller.h/.cpp`, `DispCtrl.pro`, `docs/internal_protocol.md`, `docs/changes_2025-12-25.md`
- Minor edits: various .pro inclusions, encoding flags and other build adjustments.

Testing:
- Performed a Debug build successfully using CMake/Ninja (local build succeeded).
