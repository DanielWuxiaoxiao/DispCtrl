主旨: 对齐协议与 UI；修复 overlay 初始化与退出问题；补充 BIT 报告显示；同步构建列表

详细说明：
- 将协议结构 `BeamControl` 与文档对齐：移除发射起始字段（tranStart*），将 sampleLen 重命名为 sampleEnd；更新 freqID 说明（9.0~9.8GHz 对应 0~8，下发时乘以 10）。
- 在波形/采样对话中移除发射起始相关控件；将频点下拉改为 9.0~9.8GHz，发送时使用 `index * 10`，恢复时用 `/ 10`。
- 补充并保存最新的 BITReport；重写雷达健康对话（onRadarSystemClicked）以 4x2 位图方式显示 8 位 BIT 状态，并增加电源状态指示（正常/异常）。
- 删除 `mainoverlayout.ui` 中的固定 geometry，改为让布局管理尺寸；将 overlay 作为子控件创建并使用 `QTimer::singleShot(0,...)` 延迟设置几何，避免 Linux 下初始化时控件堆叠到左上角的问题。
- 修正退出流程：将确认对话父窗口改为 `nullptr` 并使用 `QTimer::singleShot(0, qApp, &QApplication::quit)` 延迟退出，避免析构/双释放问题。
- 在 CMakeLists.txt / DispCtrl.pro 中同步缺失的源文件（例如 customspinboxstyle、servocontrol 等），修复 Linux/CMake 下的 undefined vtable / 链接错误。
- 其他小修复：头文件 includes（如 QGridLayout、QTimer）、将 resizeEvent 实现移动至 .cpp 以避免不完整类型的头内实现。

影响范围：
- 修改的文件涉及 UI (.ui/.cpp/.h)、MainWindow/Overlay 初始化、paramWidget 波形对话、Basic/Protocol.h、以及构建文件 (CMakeLists.txt, DispCtrl.pro)。

（注：Windows 下的 MSVC/CMake 构建仍提示缺失标准头，属于本地工具链/环境配置问题，不在本次提交修改范围。）
