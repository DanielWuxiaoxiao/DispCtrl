# A显 + CFAR门限叠加

## 功能描述

接收信号处理分系统发送的某一方位的回波幅度序列（A显数据），在独立窗口中绘制：
- 蓝色曲线：原始回波幅度（PC后）
- 绿色曲线：MTD后幅度
- 橙色虚线：CFAR检测门限
- 红色标记：CFAR已检到的单元

## 新增协议结构体

见 `Basic/Protocol.h`：

```cpp
// A显数据（信处 → 显控）消息ID: 0xCC01
// 端口: SIG_2_DISP_PORT3 = 6005 / DISP_GET_SIG_PORT3 = 8005
struct AScanData { ... };
```

## 触发方式

- 在PPI上右键点击某一方位 → 弹出A显窗口显示该方位的数据
- 或连续实时显示最新收到的方位线
