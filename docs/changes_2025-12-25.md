# 2025-12-25 工作区修改摘要

## 本次改动

- 新增外部雷控链路占位收发：系统控制 512B、控制回执 64B、伺服控制 32B、伺服回执 32B。

- 配置新增默认 IP/端口/ID：`RADAR_CTRL_IP=192.168.1.16`，`SCHED_IP=192.168.1.5`，`EXT_SYSCTRL_SRC=6001`，`EXT_SYSCTRL_DST=8001`，`EXT_ACK_DST=8002`，`RADAR_CTRL_ID=0xBB07`。

- 添加 `ExternalCtrlManager` 并在 `Controller` 中暴露发送接口与回执信号。

- 追加外部链路占位说明至 `docs/internal_protocol.md`。

## 使用提示

- 调用 `Controller::sendExternalSystemControl` 发送 512B 控制表，`Controller::sendExternalServoControl` 发送 32B 伺服帧；长度不符直接拒绝发送。

- 回执信号：`externalSystemCtrlAck(QByteArray)`、`externalServoAck(ExternalServoAck32)`、`externalCtrlLog(QString)`。

- 如需调整网络参数，请修改 `config.toml` 的 `network.ips` 与 `network.ports`。

## 验证

- Debug 构建已通过：`cmake --build build/debug --config Debug -- -j`
