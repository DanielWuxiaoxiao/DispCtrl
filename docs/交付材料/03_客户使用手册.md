# 雷达显控软件使用手册

适用对象：雷达操作员及客户使用人员。整理日期：2026-10-27。

本手册介绍当前软件的常用操作。不同现场启用的功能和操作权限可能不同，请以交付版本中实际显示的按钮为准。安装和网络配置由交付工程师完成。

## 1. 日常使用流程

**启动软件 → 检查健康状态 → 核对位置和工作模式 → 开始工作 → 查看目标 → 按需下发光电／总控 → 结束工作。**

开始前确认设备已连接、电源和网络就绪。若画面中有“测试航迹”“测试点迹”或离线回放内容，应先确认当前正在使用真实雷达数据。

## 2. 认识主界面

| 区域 | 用途 |
| --- | --- |
| P显 | 从平面查看目标方位、距离、历史航迹和扫描范围 |
| B显 | 查看目标距离与方位的关系 |
| 高显 | 查看目标距离与高度的关系 |
| 3D | 从空间角度查看航迹，可按交付版本使用 |
| 雷达控制 | 处理软件启停、TWS／TAS、待机、发射等 |
| 参数设置 | 阵面、伺服、信号处理等设置 |
| 航迹表 | 按批号查看目标信息 |
| 健康管理 | 查看设备、软件和通信状态 |
| 操作日志 | 查看操作记录和错误提示 |

目标“批号”是选取和下发目标时使用的编号。检测点是一次检测结果，航迹是连续跟踪结果；两者不能互相替代。

## 3. 开始工作

1. 从交付的快捷方式启动软件。
2. 打开“健康管理”，检查本机网络、处理软件和阵面状态。异常时先联系维护人员确认。
3. 核对左上角雷达位置；如需要，按第4节配置。
4. 按现场流程使用“处理软件启动”，等待健康页显示相应状态。
5. 选择“TWS模式设置”或“TAS模式设置”，核对参数后点击“确定下发”。
6. 如处于待机状态，使用“进入工作”；模式下发也可能按当前流程自动退出待机，请观察按钮和回送状态。
7. 需要发射时点击“开启发射”，按确认提示操作，并在健康页核对设备状态。

“开启发射”是一个操作按钮；已发出请求不等于设备已经执行。以健康状态和设备回送共同判断。阵面开启数量、工作模式和发射开关是不同设置。

### TWS与TAS怎么选

| 模式 | 使用方式 |
| --- | --- |
| TWS | 按现场设定的扫描方式进行搜索和跟踪 |
| TAS | 设置需要关注的方位空域，由软件计算相应的伺服指向 |

TAS方位范围按界面限制设置，超过90°会提示。TAS可选择固定频点或“随机跳频”，后者需现场设备支持。采样、波形和门限参数使用交付工程师给定值。

“确定下发”用于当前操作；需要下次启动继续使用时，使用该窗口提供的保存按钮并确认保存成功。

## 4. 配置经纬高和姿态

P显左上角只需点击位置配置按钮。当前有两种界面，按实际看到的标题操作。

### “配置雷达经纬高/姿态”

填写经度、纬度、海拔高度、阵面偏航和倾角。窗口会带入当前值，五项都需要有效数字。

- 经度、纬度、偏航和倾角单位为度；海拔高度单位为米。
- “确定”：本次运行使用填写的值。
- “保存本地”：保存为下次启动的默认值，同时立即应用。
- “取消”：放弃本次编辑。

通用窗口海拔范围为-1000～5000m。若保存失败，按提示联系维护人员检查文件权限。这里的海拔是雷达安装位置的海拔，不是目标相对高度。

### “手动配置经纬高”

填写经度、纬度和海拔高度，点击“确定”。此窗口用于当前启用的电磁联动功能，设置在本次运行有效；“恢复自动”返回设备定位／现场默认位置。它不提供姿态修改或本地保存。

修改后若涉及地图或其它联动设备，请让交付工程师确认使用的是哪一类位置设置。

## 5. 查看和选择目标

1. 在P显中查看点迹和航迹，也可在航迹表中按批号查找。
2. 点击目标查看信息，注意批号、距离、方位、高度和更新时间。
3. 对目标或标签点击右键，可使用当前版本提供的关注、手动跟踪或设备下发功能。
4. 重点观察目标可选择“关注”，取消时选择“取消关注”。

检测点、普通航迹、TBD和协同航迹入口可能按现场配置隐藏。光电和总控快捷下发主要使用当前有效的普通航迹，过期、已消批或仅用于回放的批号可能无法下发。

量程、缩放和地图切换只改变观察方式，不会自动修改雷达处理参数。扫描指示在当前版本中表现为外圈红色短标；没有贯穿中心的扫描线不一定是故障。

### 多屏和分离窗口

支持分离的页面可拖到另一显示器。最大化按窗口所在屏幕展开，恢复后返回原大小。若3D页面空白，先确认普通航迹是否正常，再向维护人员提供截图和日志，不要反复更改系统图形设置。

### 显清

“显清”用于清理显示。它不能代替“停止下发”，也不保证取消已经选择的外部设备上报；需停止联动时，使用该设备对应的停止操作。

## 6. 光电和总控操作（按现场启用）

### 6.1 光电目指

1. 先在“光电目指状态”确认连接正常。
2. 点击“光电(F6)”并输入普通航迹批号，或右键目标选择下发。
3. 当前模式同时选择一个目标；换新批号后，旧目标停止后续下发。
4. 在状态窗口查看“最近下发”“当前批次回传”“上一批次回传”。
5. 结束时点击“停止下发”，或使用目标右键的停止操作。

“等待回传”表示尚未取得设备反馈，不是已执行。持续提示与单次确认的操作方式由现场配置决定。停止后已到达对端的指令不能撤回。

### 6.2 显示“光电V2(F6)”或“激光(F6)”时

同样按批号选择目标，但操作窗口与反馈能力不同。

| 当前入口 | 常用操作 | 注意事项 |
| --- | --- | --- |
| 光电V2(F6) | 目标引导；“光电V2控制”中查看状态和设备控制 | 关闭窗口不等于设备停止运动；需要时主动下发停止 |
| 激光(F6) | 持续上报选定目标；按版本提供自动上报 | 自动模式与手动选择不同，结束时检查各自开关 |

三种F6入口由现场选定的协议决定。若按钮不显示，先让维护人员核对功能开关和权限。

### 6.3 总控主动上报

点击“总控主动上报(F7)”，输入普通航迹批号并确认；也可右键目标开启手动上报。需要本机通信和登录正常。自动上报若已开启，应在结束时单独检查。

### 6.4 电磁设备

在“电磁设备通信”查看状态和上报开关。右键普通航迹可持续下发／停止，右键检测点可单次下发。自动上报和人工选中是不同开关；关闭自动后，已手动选择的目标仍可能继续下发。

## 7. 健康状态怎么判断

| 状态 | 能说明什么 |
| --- | --- |
| 本机网络正常 | 本机对应网卡和地址可用 |
| 对端网络可达 | 对端能响应网络检测 |
| UDP／TCP正常 | 本机通信入口或连接已建立 |
| 数据源有更新 | 软件正在收到数据；仍须区分真实、测试或回放 |
| 协议回传正常 | 收到符合当前接口要求的报文 |
| 设备处理反馈 | 对端已返回相应业务结果 |

绿灯不代表所有环节都已完成。有些接口没有常规应答，暂时没有回传也不一定断网。设备状态的默认占位值不能作为设备实际正常的依据。

## 8. 数据存储与回放

“数据存储管理”用于启动／停止保存、查看记录以及使用已提供的删除或离线处理操作。选择正确的数据编号，执行后查看结果提示；删除前确认记录用途。

总控录制回放和离线RAE绘图属于独立功能，不是同一种记录格式。回放目标只用于分析与显示，不应作为现场实时目标依据。具体保存目录、磁盘空间和导出方式由交付人员说明。

## 9. 结束工作

1. 停止光电、总控和电磁的手动／自动目标下发。
2. 按现场流程关闭发射、进入待机，并核对状态。
3. 如需停止记录，先停止数据保存并确认结果。
4. 按现场流程关闭处理软件，最后退出显控。

不要仅靠关闭某个状态窗口判断联动已停止。

## 10. 常见问题

| 现象 | 操作员先检查 |
| --- | --- |
| 没有目标 | 健康管理、处理软件和工作状态；是否选错显示页／量程；是否确实有目标数据 |
| 有目标但不能下发 | 批号是否为当前普通航迹、是否消批、对应设备是否连接／登录 |
| 光电无响应 | 看状态窗口是未连接、等待还是超时，记录批号和发生时间 |
| 位置显示不符 | 核对经纬高单位和当前配置窗口，联系维护人员确认位置来源 |
| 保存后重启未生效 | 是否点了保存并成功；请维护人员检查实际配置文件 |
| 程序变慢 | 记录目标数量、是否正在回放、发生时间和截图，联系维护人员 |
| 菜单或按钮缺少 | 核对交付功能、当前权限和启用配置 |

报障时提供软件版本、时间、截图、目标批号、操作步骤及当时日志。避免只说“灯亮了但没数据”，应说明健康页哪项正常、哪项异常。

本手册按当前代码和界面文字整理，尚未对本次工作区运行截图逐项验收。正式交付时应由现场工程师核对按钮名称、启用功能和操作顺序。
