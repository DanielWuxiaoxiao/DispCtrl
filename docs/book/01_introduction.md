# 第1章 前言与项目目标

本章概述 DispCtrl 项目的背景、目标与定位。

## 背景
随着雷达应用场景的多样化与实时性要求不断提升，操作员对雷达显控系统的可视化、交互性、扩展性提出了更高要求。DispCtrl 旨在提供一套基于 Qt 的高性能雷达显示与控制框架，支持 PPI / 扇区显示、地图叠加、航迹管理与外部雷控链路。

## 项目目标
- 实时展示高吞吐量的目标数据（检测点、航迹）。
- 支持多种地图显示模式并能灵活配置（2D/3D/无图/暗色）。
- 提供稳定的网络接收与链路管理（本地与外部雷控/伺服）。
- 易于二次开发、协议扩展与部署。

## 读者对象
本专著面向系统工程师、嵌入式/Qt 开发人员、测试与维护工程师。假定读者具备 C++ 与 Qt 基础知识。
