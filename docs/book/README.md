# DispCtrl 专著（项目文档集）

本目录包含基于 DispCtrl 项目源码（Qt 5.14 / C++17）整理的完整技术专著，适用于开发人员、系统集成与维护人员。文档以独立章节形式组织，便于阅读与发布。

目录：

1. 01_introduction.md — 前言与项目目标
2. 02_requirements.md — 功能与非功能需求
3. 03_architecture.md — 总体架构与设计原则
4. 04_protocols.md — 协议与数据格式（详细）
5. 05_core_modules.md — 核心模块详解
6. 06_data_flow.md — 数据流与处理流程
7. 07_configuration.md — 配置说明（config.toml）
8. 08_build_deploy.md — 构建、部署与跨平台注意事项
9. 09_testing.md — 测试策略与性能评估
10. 10_extensibility.md — 扩展、二次开发与最佳实践
11. 11_ops_troubleshooting.md — 运维与故障排查手册
12. 12_security_reliability.md — 安全性与可靠性
13. 13_code_guidelines.md — 代码规范与贡献流程
14. 14_appendix.md — 附录（消息字典、示例配置）
15. 15_change_log.md — 更新历史

每章均可独立阅读。要生成 PDF 或 HTML，请使用支持多文件编译工具（例如 Pandoc 或 mdBook）。
