# 第3章 总体架构与设计原则

## 分层架构
- 网络层（UDP）：负责接收原始报文并做初步缓冲。
- 管理层（Manager）：解析、缓存、合并与分发各类数据（Det/Tra/TBD/External）。
- 控制层（Controller）：总控逻辑、信号桥接、窗口控制、配置下发。
- 视图层（PPI/扇区/地图/表格）：负责渲染与人机交互。

## 设计原则
- 单一职责：每个 Manager 只负责一类数据的解析与管理。
- 解耦通信：Qt 信号/槽作为模块间通信手段，避免强耦合。
- 主线程负责 UI：所有 UI 更新在主线程执行，数据处理在后台线程完成。
- 可配置性优先：使用 `config.toml` 作为主配置项，便于现场调参与版本控制。
